# GROUNDED ARCHIPELAGO -- LOCATION REVIEW (temporary)
#
# Every check the mod has now, plus candidates it could have.
#   [x] = keep / add as a check      [ ] = don't use
# Edit the boxes, add notes after a "#" on any line, then tell Claude --
# this file then becomes the rule for which locations exist.
# To rename a check to match the game, add "=> New Name" after its name,
# e.g. "[x] Item: Salty Jewel => Item: Salt Jewel   # needs: ...". Leave
# the old name in front: it's what the mod reports.
#
# "needs:" tokens -- c1/c2/c3 = Tier 1/2/3 weapon (+ full armor of that tier
# for c2/c3); axe1-3, hammer1-3, shovel1-2 = harvesting tool of at least that
# tier ("shovel" = shovel1); dagger1-3 = Bone / Spider Fang / Widow Dagger
# (underwater, so they include Diving Gear); gas = Gas Mask; dive = Diving
# Gear; canister = Haze canister plugged (Gas Mask + Tier 2); undershed =
# Undershed; smoothie / cookery / oven = Smoothie Station / Cookery (meals) /
# Oven (globs, jewels, boss summon keys); kill:<boss> = that boss's needs.
# "free" (or no needs) = nothing. To change one, write e.g. "# needs: shovel2".
# Item/craft/landmark checks sit under a "### <group>" heading -- a biome,
# or for crafts Utility / Weapons / Armor / Meals; that's the tab the
# client's Tracker shows them in. "needs:" is read on Item and Landmark lines.
# After editing, run:  python connector/tools/apply_location_review.py
#
# Sections marked (CANDIDATE) aren't checks yet; detection status is noted.
